# NOIR / Personal Portfolio

React + Vite personal portfolio starter for a visual designer, AI designer and brand designer.

## Run locally

```bash
pnpm install
pnpm dev
```

Then open the local URL printed by Vite.

## Where to customize

- `src/main.jsx`: replace the placeholder profile copy, metrics, project names and contact details with the final resume information.
- `src/styles.css`: visual system, responsive layout and color tokens.

The current visual direction uses a dark editorial layout, acid-green accent, typography-led hero, remote image placeholders, a video background with poster fallback, responsive mobile behavior and clickable project detail placeholders.
